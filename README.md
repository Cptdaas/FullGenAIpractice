# 🚀 Full GenAI Practice & Training

## Learning, Training & Mastering the Full GenAI Stack (Including Agentic AI)

This repository is a **hands-on learning and training workspace** focused on understanding and implementing the **complete Generative AI (GenAI) stack**, including **Agentic AI concepts**, tools, and real-world workflows.

Here, the goal is not just theory — but **deep practical understanding** of:
- How GenAI systems are built
- How Agentic AI works internally
- How different components interact in a real project setup

This repo is designed as a **progressive learning journey**, where each directory represents a structured phase of training.

---

## 🧠 What You Will Learn

- Fundamentals of Generative AI
- Prompt Engineering (basic → advanced)
- LLM interaction patterns
- Agentic AI concepts and workflows
- Tool usage and orchestration
- Data formats, JSON schemas, and structured outputs
- Practical experiments and notebooks
- Clean project structuring for real-world GenAI systems
